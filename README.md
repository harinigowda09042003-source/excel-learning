# 🍕 Pizza Sales & Delivery Analysis Using Excel

## 📌 Project Overview

This project explores pizza order and delivery data using Microsoft Excel. The objective is to identify ordering patterns, understand customer preferences, and examine how delivery distance relates to delivery duration and delays.

The project demonstrates how spreadsheet analysis, PivotTables, and charts can help transform raw data into understandable business insights.

## 🎯 Business Objectives

- Identify the most frequently ordered pizza types.
- Determine the most popular pizza sizes.
- Explore monthly order trends.
- Examine customer payment-method preferences.
- Investigate the relationship between delivery distance, delivery duration, and delays.

## 🛠️ Tools and Techniques

- Microsoft Excel
- PivotTables
- Mathematical and logical functions
- Column, bar, line, pie, and combination charts
- Data summarization and exploratory analysis

## 📊 Dataset

The workbook contains 1,004 order records with fields such as:

- Order ID
- Restaurant name and location
- Order and delivery times
- Delivery duration
- Pizza size and type
- Topping count
- Delivery distance
- Payment method
- Delay duration

The workbook's dataset is used for analytical practice. Its source and representativeness should be verified before drawing conclusions about the wider pizza delivery industry.

## 🔍 Analysis and Key Findings

### 1. Pizza Type Analysis

A PivotTable and column chart were used to compare order counts by pizza type.

- Non-Veg: 216 orders
- Veg: 202 orders
- Cheese Burst: 188 orders

These were the three most frequently ordered categories in the workbook.

### 2. Pizza Size Analysis

A bar chart was used to compare order volumes across pizza sizes.

- Medium: 429 orders
- Large: 240 orders
- XL: 203 orders
- Small: 132 orders

Medium pizzas represented the largest share of recorded orders.

### 3. Monthly Order Trends

A line chart was used to explore changes in order volume throughout the year.

- August recorded the highest monthly count, with 117 orders.
- September followed with 105 orders.
- July recorded the lowest monthly count, with 49 orders.

These are patterns in the supplied dataset and do not establish a recurring seasonal trend by themselves.

### 4. Payment Method Analysis

A pie chart was used to compare recorded payment-method categories.

- Card: 276 orders
- UPI: 271 orders
- Wallet: 208 orders
- Cash: 202 orders
- Hut Points: 24 orders
- Domino's Cash: 23 orders

The categories were compared to understand the distribution of payment methods in the dataset.

### 5. Delivery Distance and Duration

A combination chart compared average delivery duration and average delay across recorded delivery distances.

The workbook shows that longer-distance groups generally have higher average delivery durations. This suggests an association in the dataset, but it does not establish that distance alone causes longer delivery times.
